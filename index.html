Sobre a FYFHON

A FYFHON é uma linguagem de programação experimental criada em Python e inspirada no Dinofauro, o famoso dinossauro azul que ficou conhecido na internet pelo seu jeito peculiar de falar. O meme popularizou o chamado dinofaurês, uma forma divertida de escrever palavras trocando algumas letras por “F”.

A ideia da FYFHON é levar essa brincadeira para o mundo da programação. Em vez de usar os comandos tradicionais do Python, a linguagem utiliza instruções próprias, escritas no estilo do dinofaurês. Assim, comandos comuns ganham nomes como EFCUTA EFFA!, FEM-FINDO! e FENHA UM FOM FIA!.

Apesar dos nomes engraçados, a FYFHON funciona como um projeto real de programação: seu interpretador é desenvolvido em Python e tem a função de ler os comandos escritos pelo usuário e executar as instruções reconhecidas pela linguagem.

Exemplos de código

Veja como os comandos podem ser usados em programas FYFHON.

1. Mostrar uma mensagem

FEM-FINDO!

EFCUTA EFFA! ("Olá, mundo!")

FENHA UM FOM FIA!

O programa exibe a mensagem “Olá, mundo!” na tela.

2. Ler o nome do usuário

FEM-FINDO!

É VERFADE QUE nome É A MEFMA COIFA QUE FALE MINHA LINFA ("Digite seu nome: ")
EFCUTA EFFA! (nome)

FENHA UM FOM FIA!

O programa pede o nome, guarda o texto na variável nome e depois o mostra.

3. Usar uma condição

FEM-FINDO!

É VERFADE QUE idade É A MEFMA COIFA QUE 18

FICA FENDO IFFO idade É MAIOR OU IGUAL A 18 ENFÃO FAZ AFFIM
    EFCUTA EFFA! ("Maior de idade")
NOFFA FINHORA QUE RAIFA!
    EFCUTA EFFA! ("Menor de idade")
ACABOU A CONVERFA

FENHA UM FOM FIA!

O programa verifica a idade e exibe uma mensagem conforme o resultado da condição.

4. Repetir com FOR

FEM-FINDO!

FAZ DE NOFO! i DE 1 ATÉ 5 ENFÃO FAZ AFFIM
    EFCUTA EFFA! (i)
ACABOU A CONVERFA

FENHA UM FOM FIA!

O laço mostra os números de 1 até 5.

5. Escolher um caso

FEM-FINDO!

É VERFADE QUE opcao É A MEFMA COIFA QUE 2

FAMO VER QUAL É? opcao ENFÃO FAZ AFFIM
    É EFFE 1 ENFÃO FAZ AFFIM
        EFCUTA EFFA! ("Você escolheu um")
    É EFFE 2 ENFÃO FAZ AFFIM
        EFCUTA EFFA! ("Você escolheu dois")
    É EFFE _ ENFÃO FAZ AFFIM
        EFCUTA EFFA! ("Opção desconhecida")
ACABOU A CONVERFA

FENHA UM FOM FIA!

O programa compara a opção com os casos definidos e executa o bloco correspondente.

Como executar

Salve o código em um arquivo com a extensão .fyfhon e execute-o usando o interpretador Python da linguagem.

py fyfhon.py exemplo.fyfhon

O arquivo fyfhon.py precisa estar disponível na pasta do projeto. Não execute o arquivo FYFHON diretamente com o Python.
